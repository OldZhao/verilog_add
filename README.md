# 400 输入 / 200 输出两两求平均模块(基础版 + 优化版)

本仓库包含两种实现,功能与输入输出关系完全一致:

- **基础版** `avg_pairs.v`:先缓存全部 400 个输入,收齐后连续输出 200 个结果;
- **优化版** `avg_pairs_opt.v`:利用配对数据相差 100 个输入周期的特点,只使用
  1 个 100×10bit 缓冲,输入和输出重叠进行。

## 1. 题目

输入 400 个 10bit 数据,每次输入一个数,记为 `i000` ~ `i399`;
输出 200 个 10bit 数据,每次输出一个数,记为 `o000` ~ `o199`。

输入和输出的关系(题面给出的示例):

- `o000 = (i000 + i100) / 2`
- `o002 = (i001 + i101) / 2`
- `o100 = (i200 + i300) / 2`
- `o101 = (i201 + i301) / 2`

> 说明:第 2 条示例 `o002 = (i001 + i101)/2` 与其余三条的规律不一致,
> 应为 `o001 = (i001 + i101)/2` 的笔误。否则该映射既与 `o100/o101`
> 的例子矛盾,也会使 `o001` 没有定义。本文按修正后的规律实现。

## 2. 归纳出的规律

对 `c = 0..99`:

| 输出 | 表达式 |
|---|---|
| `o[c]`(`o000` ~ `o099`) | `(i[c] + i[c+100]) / 2` |
| `o[100+c]`(`o100` ~ `o199`) | `(i[200+c] + i[300+c]) / 2` |

即把 400 个输入分成 4 组、每组 100 个:第 1、2 组对应位置求平均得到前
100 个输出,第 3、4 组对应位置求平均得到后 100 个输出。

## 3. 基础版硬件设计(avg_pairs.v)

设计文件:`avg_pairs.v`

### 3.1 存储结构

使用 4 个 bank,每个 bank 为 100 x 10bit:

| bank | 内容 |
|---|---|
| `bank0` | `i000` ~ `i099` |
| `bank1` | `i100` ~ `i199` |
| `bank2` | `i200` ~ `i299` |
| `bank3` | `i300` ~ `i399` |

每个输出所需的两个数恰好来自两个不同的 bank,因此可以同一周期读取、
相加并寄存输出,不需要双端口存储器。

### 3.2 状态机

只有两个状态:

1. **S_LOAD**:接收 400 个输入,按顺序写入 4 个 bank;收满 400 个后进入 `S_OUT`。
2. **S_OUT**:连续 200 个时钟输出 `o000` ~ `o199`;完成后回到 `S_LOAD`,
   可以接收下一帧。

### 3.3 数据通路

- 读地址:输出序号小于 100 时从 `bank0`/`bank1` 的同一列读取;
  否则从 `bank2`/`bank3` 的同一列读取。
- 加法显式扩展到 11bit(`{1'b0, a} + {1'b0, b}`),防止两个 10bit 数
  相加时丢失最高进位。
- `sum[10:1]` 实现除以 2,结果为向下取整;若需要四舍五入,可改为
  `sum[10:1] + sum[0]`。

### 3.4 接口与时序

| 信号 | 方向 | 说明 |
|---|---|---|
| `clk` | 输入 | 时钟 |
| `rst_n` | 输入 | 异步复位,低电平有效 |
| `in_valid` | 输入 | 输入数据有效 |
| `in_data[9:0]` | 输入 | 输入数据 `i000` ~ `i399` |
| `in_ready` | 输出 | 为 1 表示可以接收输入 |
| `out_valid` | 输出 | 输出数据有效 |
| `out_data[9:0]` | 输出 | 输出数据 `o000` ~ `o199` |

时序:复位后 `in_ready = 1`,在上游 `in_valid` 有效时每个时钟接收一个数,
共 400 个;收齐后用 200 个连续周期输出结果,`out_valid` 同时拉高;随后
自动返回接收状态。输出期间 `in_ready = 0`,上游需要遵守该反压信号
(如果只发送单帧 400 个数,可以忽略 `in_ready`)。

## 4. 优化版(avg_pairs_opt.v)

基础版需要 4 个 100×10bit 的 bank(共 4000 bit),并且要等 400 个输入全部
收齐后才开始输出。优化版在不改变功能和数值结果的前提下,利用"参与平均的
两个数相差 100 个输入周期"这一特点,用时间换空间,只保留 1 个
100×10bit 的缓冲(共 1000 bit)。

### 4.1 实现思路

以 `n` 表示第 n 个有效输入(n = 0..399),`c = n mod 100`:

| n | 操作 |
|---|---|
| 0 ~ 99 | `sample_buf[c] <= i[n]`,保存 `i000..i099` |
| 100 ~ 199 | `sample_buf[c] <= (sample_buf[c] + i[n]) >> 1`,把 `o000..o099` 暂存回同一位置 |
| 200 ~ 299 | 输出 `sample_buf[c]`(即 `o[c]`);同时 `sample_buf[c] <= i[n]`,保存 `i200..i299` |
| 300 ~ 399 | 输出 `(sample_buf[c] + i[n]) >> 1`(即 `o100..o199`),之后该位置可供下一帧复用 |

第 3 段的 `sample_buf[c]` 是"同一地址先读后写":读出的旧值是之前算好的
`o[c]`,写入的是刚到达的 `i[200+c]`。在 Verilog 寄存器数组中使用非阻塞
赋值即可保证读到旧值;若映射到 Block RAM,需要 read-first
(read-before-write)模式。

### 4.2 相对基础版的改动点

1. **存储复用**:4 个 bank 改为 1 个 100×10bit 缓冲;输入、中间结果
   `o000..o099`、后半段输入 `i200..i299` 分时复用同一块存储。
2. **控制简化**:由"`S_LOAD` 400 拍 → `S_OUT` 200 拍"的两状态机,
   改为 4 段循环的 `phase`(2bit)+ `col`(7bit)计数器;不再需要
   `in_cnt`、`out_cnt`、`wr_bank`、`wr_col` 等计数器。
3. **输入输出重叠**:第 3、4 段在接收输入的同时输出结果,每 400 个输入
   周期即可完成一帧;不再需要 `in_ready` 在输出阶段反压上游,支持
   帧与帧背靠背连续处理。
4. **读取端口减少**:基础版在输出阶段要同时读两个 bank;优化版每个
   周期只需要一次读和一次写,数据通路更简单。
5. **数值处理不变**:仍然使用 11bit 加法防止进位丢失,`sum[10:1]`
   实现向下取整的 `/2`。

### 4.3 节约分析

| 项目 | 基础版 | 优化版 | 节约 |
|---|---|---|---|
| 存储 | 4×100×10 = 4000 bit | 1×100×10 = 1000 bit | 减少 75% |
| 每帧周期 | 400 输入 + 200 输出 = 600 | 400(输入输出重叠) | 减少约 33%,吞吐 1.5× |
| 首个输出延迟 | ≈401 周期 | ≈201 周期 | 约减半 |
| 控制计数器 | `state`/`in_cnt`/`out_cnt`/`wr_bank`/`wr_col` | `phase`/`col` | 明显简化 |
| 输出连续性 | 200 个连续周期 | 200 个连续周期 | 不变 |

存储 100 个样本是理论下限:配对的两个数相隔 100 个输入,按顺序处理时
至少要缓存其中 100 个。输出侧,`o199` 依赖 `i399`,若要求 200 个结果
连续输出,最后一个结果最早也只能在第 399/400 个周期得到,因此第一个
结果最早也只能在约第 200 个周期出现;优化版输出寄存一拍,实际在约
第 201 个周期给出 `o000`,已接近该下界。

### 4.4 代价与注意事项

- 第 3、4 段的输出与输入进度绑定:上游暂停输入时,输出也相应暂停。
- 同一地址"先读后写"是复用同一块存储的前提;若综合成 Block RAM,
  必须使用 read-first 模式,或让综合工具将其实现为寄存器/LUTRAM。
- 如果更看重首输出延迟而不要求输出连续,可以让第 2 段直接输出
  `o000..o099`,首输出可提前到约第 101 个周期,但 `o099` 和 `o100`
  之间会出现 100 个周期的输出空档。

## 5. 验证

### 5.1 基础版(avg_pairs.v)

验证文件:`tb_avg_pairs.v`

- 随机生成 400 个 512 ~ 1023 的输入,保证任意两数之和都超过 10bit,
  可以检验进位处理;
- 用参考模型计算 200 个期望值,逐周期与 `out_data` 比对;
- 随机激励同时包含奇数和与偶数和,可检验 `/2` 的向下取整;
- 仿真结果:`PASS: 200/200 outputs correct`。

关键示例输出:

```
o000 = (i000=805 + i100=570)/2 = 687
o001 = (i001=966 + i101=1011)/2 = 988
o100 = (i200=791 + i300=824)/2 = 807
o101 = (i201=657 + i301=846)/2 = 751
```

### 5.2 优化版(avg_pairs_opt.v)

验证文件:`tb_avg_pairs_opt.v`

- 使用相同的随机输入和参考模型;
- 连续发送两帧(共 800 个输入),检查两帧共 400 个输出,验证帧与帧
  背靠背处理的正确性;
- 仿真结果:`PASS: 400/400 outputs correct (2 frames back-to-back)`。

## 6. 仿真方法

```bash
# 基础版
iverilog -o sim avg_pairs.v tb_avg_pairs.v
vvp sim

# 优化版
iverilog -o sim_opt avg_pairs_opt.v tb_avg_pairs_opt.v
vvp sim_opt
```

查看波形:

```bash
gtkwave tb_avg_pairs.vcd       # 基础版
gtkwave tb_avg_pairs_opt.vcd   # 优化版
```
