# 400 输入 / 200 输出两两求平均模块

## 1. 题目

输入 400 个 10bit 数据,每次输入一个数,记为 `i000` ~ `i399`;
输出 200 个 10bit 数据,每次输出一个数,记为 `o000` ~ `o199`。

输入和输出的关系(题面给出的示例):

- `o000 = (i000 + i100) / 2`
- `o002 = (i001 + i101) / 2`
- `o100 = (i200 + i300) / 2`
- `o101 = (i201 + i301) / 2`

> 说明:第 2 条示例 `o002 = (i001 + i101)/2` 与其余三条的规律不一致,
> 应为 `o001 = (i001 + i101)/2` 的笔误。否则该映射既与 `o100/o101`
> 的例子矛盾,也会使 `o001` 没有定义。本文按修正后的规律实现。

## 2. 归纳出的规律

对 `c = 0..99`:

| 输出 | 表达式 |
|---|---|
| `o[c]`(`o000` ~ `o099`) | `(i[c] + i[c+100]) / 2` |
| `o[100+c]`(`o100` ~ `o199`) | `(i[200+c] + i[300+c]) / 2` |

即把 400 个输入分成 4 组、每组 100 个:第 1、2 组对应位置求平均得到前
100 个输出,第 3、4 组对应位置求平均得到后 100 个输出。

## 3. 硬件设计

设计文件:`avg_pairs.v`

### 3.1 存储结构

使用 4 个 bank,每个 bank 为 100 x 10bit:

| bank | 内容 |
|---|---|
| `bank0` | `i000` ~ `i099` |
| `bank1` | `i100` ~ `i199` |
| `bank2` | `i200` ~ `i299` |
| `bank3` | `i300` ~ `i399` |

每个输出所需的两个数恰好来自两个不同的 bank,因此可以同一周期读取、
相加并寄存输出,不需要双端口存储器。

### 3.2 状态机

只有两个状态:

1. **S_LOAD**:接收 400 个输入,按顺序写入 4 个 bank;收满 400 个后进入 `S_OUT`。
2. **S_OUT**:连续 200 个时钟输出 `o000` ~ `o199`;完成后回到 `S_LOAD`,
   可以接收下一帧。

### 3.3 数据通路

- 读地址:输出序号小于 100 时从 `bank0`/`bank1` 的同一列读取;
  否则从 `bank2`/`bank3` 的同一列读取。
- 加法显式扩展到 11bit(`{1'b0, a} + {1'b0, b}`),防止两个 10bit 数
  相加时丢失最高进位。
- `sum[10:1]` 实现除以 2,结果为向下取整;若需要四舍五入,可改为
  `sum[10:1] + sum[0]`。

### 3.4 接口与时序

| 信号 | 方向 | 说明 |
|---|---|---|
| `clk` | 输入 | 时钟 |
| `rst_n` | 输入 | 异步复位,低电平有效 |
| `in_valid` | 输入 | 输入数据有效 |
| `in_data[9:0]` | 输入 | 输入数据 `i000` ~ `i399` |
| `in_ready` | 输出 | 为 1 表示可以接收输入 |
| `out_valid` | 输出 | 输出数据有效 |
| `out_data[9:0]` | 输出 | 输出数据 `o000` ~ `o199` |

时序:复位后 `in_ready = 1`,在上游 `in_valid` 有效时每个时钟接收一个数,
共 400 个;收齐后用 200 个连续周期输出结果,`out_valid` 同时拉高;随后
自动返回接收状态。输出期间 `in_ready = 0`,上游需要遵守该反压信号
(如果只发送单帧 400 个数,可以忽略 `in_ready`)。

## 4. 验证

验证文件:`tb_avg_pairs.v`

- 随机生成 400 个 512 ~ 1023 的输入,保证任意两数之和都超过 10bit,
  可以检验进位处理;
- 用参考模型计算 200 个期望值,逐周期与 `out_data` 比对;
- 随机激励同时包含奇数和与偶数和,可检验 `/2` 的向下取整;
- 仿真结果:`PASS: 200/200 outputs correct`。

关键示例输出:

```
o000 = (i000=805 + i100=570)/2 = 687
o001 = (i001=966 + i101=1011)/2 = 988
o100 = (i200=791 + i300=824)/2 = 807
o101 = (i201=657 + i301=846)/2 = 751
```

## 5. 仿真方法

```bash
iverilog -o sim avg_pairs.v tb_avg_pairs.v
vvp sim
```

